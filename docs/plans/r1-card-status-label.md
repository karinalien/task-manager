# R1: цветные отметки исполнителя

Статус: реализовано, подготовлено к PR по поручению Карины; main и VPS не изменены.
Ветка r1-card-status-label, база main a0da46a. 19 ноября 2026.

## Решение

По уточнению Карины метки не повторяют колонки. Список: Без отметки (серый), Принята исполнителем
(синий), Нужны уточнения (жёлтый), Невозможно выполнить (красный), Исправить (фиолетовый),
Выполнена исполнителем (зелёный). На канбане и в открытой карточке одинаковые цвет и текст.
Изменение — в редакторе подтверждённой карточки. Для трёх проблемных состояний поле комментария
обязательно; комментарий сохраняется вместе с отметкой и виден только внутри карточки.
Это один текущий комментарий, не журнал обсуждений. При смене метки поле очищается.
Переносы не меняют отметку, метка не меняет колонку/ветку/загрузку сама по себе.
Ранее подготовленные метки колонок заменены, не опубликованы.

## Проверки

Проверяются сохранение JSON после переоткрытия, все метки, очистка комментария, запрет пустой
причины, длина, ревизии и отсутствие GitHub-вызовов. UI-тесты проверяют обе поверхности,
независимость от переносов, скрытие комментария на доске, безопасный текст и сохранение ввода при 409.
Визуальная приёмка не подтверждена: доступ к браузеру в этом чате ранее был недоступен.
